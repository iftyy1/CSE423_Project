# 3D Smart Parking Simulator

A 3D simulation game developed using Python and OpenGL. The game challenges players to navigate a car through dynamic parking scenarios while managing time, obstacles, and collision effects.

## Project Overview

The goal is to park the car accurately in green zones while avoiding red zones and dynamic obstacles. The game includes a countdown timer, scoring system, level progression, and real-time feedback such as damage and collision indicators.


## Features

### Part 01: Parking System (Core Objective)
- Green Parking Zone (Accepted Parking)
- Red Parking Zone (No Parking) with Alert Signal
- Multiple Parking Spots
- Parking Bonus
- Car Movement with Rotation

### Part 02: Car & Movement Mechanics
- Collision Detection with Objects
- Smoke on Collision
- Damage Meter
- Car Customization (Color)
- Mini Map

### Part 03: Gameplay & Progression
- Score Tracking System
- Timer System (Countdown)
- Timed Challenge Mode
- Dynamic Obstacles
- Level Switcher

### Part 04: Camera & Environment
- Adjustable Overhead Camera
- First Person / Third Person Camera View Toggle
- Day/Night Cycle 
- Display: Score, Damage, Time, Camera Mode


## Technologies Used
- Python 3
- PyOpenGL
- GLUT
